Menu Interativo

Conteúdo

Exercício de fixação do curso de Javascript com o objetivo de práticar e criar um sistema de menu interativo, onde o usuário poderá escolher entre 5 opções dentro do menu, onde as 4 primeiras deverão conter uma mensagem sinalizando a opção escolhida e a ultima opção será para encerrar o programa.

Como testar?

Basta iniciar a página HTML para ver o funcionamento do código em JS.
