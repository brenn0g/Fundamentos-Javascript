Estruturas de Repetição - FOR

Conteúdo

A estrutura de repetição FOR é utilizada para executar um bloco de código várias vezes, geralmente quando sabemos previamente quantas repetições serão necessárias.

Ela possui três partes principais: inicialização, condição e incremento ou decremento.


"PARA cada repetição, verifique a condição e execute o código enquanto ela for verdadeira."

Sintaxe:

for (inicializacao; condicao; incremento) {
    // código que será repetido
}

Exemplo:

for (let contador = 1; contador <= 5; contador++) {
    console.log(contador)
}

Neste exemplo, os números de 1 a 5 serão exibidos no console. A cada repetição, a variável contador é incrementada em 1, até que a condição se torne falsa.

Fluxo de Execução

O funcionamento do FOR segue os seguintes passos:

  • Inicializa a variável de controle.
  • Verifica se a condição é verdadeira.
  • Se for verdadeira, executa o bloco de código.
  • Executa o incremento ou decremento.
  • Retorna para verificar a condição novamente.
  • Encerra o loop quando a condição for falsa.

Cuidado com Loops Infinitos

Um erro comum ao utilizar o FOR é criar uma condição que nunca se torna falsa ou esquecer de atualizar corretamente a variável de controle.

Isso faz com que o bloco de código seja executado indefinidamente, criando um loop infinito. 

for (let contador = 1; contador <= 5; contador--) {
    console.log(contador)
}

Neste exemplo, a variável contador começa em 1 e é decrementada a cada repetição. Como ela nunca alcançará um valor maior que 5, a condição continuará verdadeira e o loop não terminará.

Exemplo Prático

let numero = Number(prompt("Digite um número:"))

for (let contador = 1; contador <= 10; contador++) {
    console.log(`${numero} x ${contador} = ${numero * contador}`)
}

O programa solicitará um número ao usuário e utilizará o FOR para exibir sua tabuada de 1 a 10 no console.
